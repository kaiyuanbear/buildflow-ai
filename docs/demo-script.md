# BuildFlow AI 面试演示稿

## 目标

在三到五分钟内演示一个可靠、可解释、具备安全边界的 AI 应用构建流程，而不是声称能执行任意模型代码。

## 演示顺序

1. **首页与账户（20 秒）**：注册或登录，指出首页仅展示本人的项目；左侧退出登录固定在侧栏底部。
2. **输入需求（20 秒）**：输入“制作一个旅行行程编辑器，支持添加每日安排、筛选日期和统计行程”。说明该提示词没有映射到预置的旅行模板。
3. **Agent 流程（45 秒）**：进入 Builder 后，展示左栏的中文事件：需求分析、蓝图请求/校验、复杂度规划、多文件生成、结构与安全校验、质量校验、逐文件保存和预览就绪。这些事件来自数据库记录，不展示模型隐藏推理。
4. **文件与预览（60 秒）**：展开中栏的 `styles/`、`src/`，选择文件查看源码；指出 manifest 控制 CSS/JS 顺序。右栏在 sandbox iframe 中运行，尝试添加、筛选或编辑内容，确认反馈会改变。
5. **版本与持久化（45 秒）**：输入一条优化要求生成 v2，打开版本历史，切回/恢复 v1；刷新页面，确认版本和预览状态保留。
6. **安全与回退（30 秒）**：说明 API key 只在服务器；生成代码不能联网、不能读取 cookie/storage、不能访问父页面。模型输出不符合严格契约时，系统会记录原因并保存明确标识的本地起步应用，而不会假装生成成功。

## 收尾

说明取舍：项目刻意没有实现任意包安装、服务器端执行或子应用部署；换取了可审查的文件白名单、可复现预览、用户所有权校验和稳定的面试演示路径。
