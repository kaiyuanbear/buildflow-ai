# BuildFlow AI

BuildFlow AI is an AI app-builder demo for the Atoms full-stack interview exercise. It turns a product request into a visible agent workflow, interactive application preview, generated files, and persistent project versions.

## Status

Implementation is in progress. The durable project specification, plan, QA checklist, and deployment guide are in `docs/`.

## Security

Never commit `.env` or API keys. `DEEPSEEK_API_KEY` is server-only and optional because the project includes a deterministic fallback.
